# Ikonex Student Management System

A full-stack enterprise-grade Student Management System (SMS) for "Ikonex Academy" built with Vue.js 3 (Frontend), Node.js/Express (Backend), and MySQL (Database).

## Features
- **Student Management:** View and manage student records.
- **Subject Management:** Organize subjects into categories.
- **Assessments:** Create assessments and track student scores.
- **Results Processing:** Calculate grades, totals, and ranks automatically.

## Prerequisites
- Node.js (v18 or higher recommended)
- MySQL Server

## Setup Instructions

### 1. Database Setup
1. Create a MySQL database (e.g., `ikonex_sms`).
2. Navigate to the `backend` directory and copy the `.env.example` file to `.env`:
   ```bash
   cd backend
   cp .env.example .env
   ```
3. Update the `.env` file with your MySQL database credentials:
   ```env
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=your_db_user
   DB_PASSWORD=your_db_password
   DB_NAME=ikonex_sms
   ```
4. Run migrations to create the required tables:
   ```bash
   npm install
   npx knex migrate:latest
   ```

### 2. Backend Setup
1. From the `backend` directory, install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
   The backend API will run on `http://localhost:3000`.

### 3. Frontend Setup
1. Open a new terminal and navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
   The frontend application will be available at `http://localhost:5173`.

## Deployment

### Backend Deployment (e.g., Render, Railway, Heroku)
1. Ensure your database is hosted online (e.g., AWS RDS, Aiven, or Railway MySQL).
2. Set the environment variables (`DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`, `PORT`) in your hosting provider's dashboard.
3. The backend start command should run the compiled JavaScript:
   ```bash
   npm run build
   npm start
   ```

### Frontend Deployment (e.g., Vercel, Netlify)
1. Ensure the API base URL in the frontend is pointing to your hosted backend URL.
2. Build the project:
   ```bash
   npm run build
   ```
3. Deploy the `dist` folder generated by the build process.

## System Usage
1. Navigate to the application in your browser.
2. Use the navigation menu to access **Subjects**, **Students**, and **Assessments**.
3. Follow the intuitive UI to add/edit records and view generated results and reports.
